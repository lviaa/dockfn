# ADR 0001：只登记固定宿主机端口

- 状态：已接受
- 日期：2026-07-27

## 背景

早期设计同时包含 Docker 发现、标签映射、候选持久化、中继、任务、对账和多部署形态。这些能力扩大了权限面，也让“把已有 Web 服务放到 fnOS 桌面”必须穿过多个状态机。

## 决策

DockFN 只登记已有 Web 服务的 `http/https + 固定宿主机端口 + path`，一个 AppSpec 对应一个 fnOS 入口。创建、更新、检测、修复、回退和移除同步执行。

正式运行方式只有 x86_64/ARM64 原生 FPK。自动登记、任务队列、持续对账、中继、Compose 独立认证、公共 URL 和完整修订历史不进入当前产品。

ADR 0002 在不改变固定端口和显式创建语义的前提下增加手动、只读发现。

## 影响

- 调用者只需理解一个 AppSpec 和同步生命周期操作。
- 没有固定宿主机端口的服务必须先由用户完成端口发布。
- DockFN 不提供反向代理，也不负责外网访问。
- 多个入口通过创建多个 DockFN 应用表达。
