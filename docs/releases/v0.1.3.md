# DockFN 0.1.3

DockFN 0.1.3 修复 fnOS 桌面入口命名不符合规范导致的登记失败，并提升 ARM64 平台的安装与打包兼容性。

本版本不改变目标 Web 服务、容器、端口或业务数据，也不增加反向代理功能。

## 修复与优化

- 新建登记壳的桌面入口名称统一为 `<appName>.main`，符合 fnOS 对应用名前缀入口的要求，修复应用中心安装后桌面入口校验失败的问题。
- FPK manifest 移除已废弃的 `arch` 字段，统一使用 `platform=x86` 或 `platform=arm` 声明目标平台。
- 移除生命周期未使用的 `setpriv` 前置依赖，避免部分 ARM fnOS 环境因缺少该命令而提前终止安装。
- 产物校验器兼容官方 `fnpack` 输出的对齐式 `key = value` manifest，同时继续核对平台、桌面入口、ELF 架构和生命周期文件。
- GitHub Actions 固定下载并校验官方 `fnpack 1.2.3`，确保线上发布包与本地正式打包流程一致。

## 验证

- 使用官方 `fnpack 1.2.3` 成功生成并校验 x86_64 与 ARM64 FPK。
- 在 QEMU `linux/arm64` 环境运行全部 Go 测试，覆盖登记壳生成、安装、应用中心状态读取和桌面入口校验。
- 从最终 ARM64 FPK 解出真实 AArch64 二进制，完成安装前检查、启动、状态检测、Unix Socket 建立和停止清理。
- 完成 Go、race、前端、格式、静态检查、类型检查和依赖安全审计。

## 升级说明

升级 DockFN 后，重新创建此前登记失败的应用入口即可。已经正常工作的入口和目标服务无需调整。

ARM64 自动化验证不能完全替代真实 ARM fnOS 应用中心；建议 ARM 用户安装后创建一个测试入口进行确认。
