# DockFN 0.1.0

DockFN 0.1.0 is the first release for registering existing Web services as fnOS application entries without taking control of the services themselves.

## Included

- Discover IPv4 Web services on the host and in Docker, including host-network containers.
- Read WatchCow metadata and match services that already have an fnOS application entry.
- Create, update, check, repair, roll back, and remove DockFN registration shells.
- Choose URL or iframe opening, configure a stable entry ID, and use automatic, URI-based, or uploaded icons.
- Detect common Web icons from page metadata and standard favicon/logo paths.
- Persist ignored discovery candidates locally and keep registered applications separated from candidates.
- Provide installation guidance, configurable shell storage volume, diagnostics, redacted logs, and cleanup controls.
- Preserve target services, containers, volumes, and business data during all DockFN operations and uninstall preparation.
- Build verified native FPK packages for x86_64 and ARM64, with Windows and POSIX packaging entry points.

## Packages

```text
dockfn-0.1.0-x86_64.fpk
dockfn-0.1.0-arm64.fpk
SHA256SUMS
```

## Compatibility notes

- x86_64 installation and core registration flows were verified on a real fnOS device.
- ARM64 packages are cross-compiled and statically verified in CI; ARM64 device installation validation is not included in this release and should be completed separately before deployment.
- DockFN does not install, start, stop, proxy, or manage the target Web service or its Docker resources.
